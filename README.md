### `03` [Trading Engine](https://github.com/tfthushaar/trading-engine-mvp)
[![Live](https://img.shields.io/badge/Live-000000?style=flat-square&logo=vercel&logoColor=white)](https://trading-engine-mocha.vercel.app)

Every layer, backward pass and optimiser written from scratch in NumPy: LSTM and GRU with backpropagation through time, dilated causal convolutions, multi-head attention. Proven correct twice over, by finite differences against a deliberately broken control that has to fail, and by matching PyTorch to 1e-10 on every parameter gradient. Accuracy lands at 55.2% against a 55.1% base rate, so the product sells the ranking instead, and a better-calibrated model that ranked worse was measured and then left unshipped.
